# Як додавати й змінювати матеріали

Усі тексти зберігаються у файлах `js/*.js`. Змінювати код не потрібно: достатньо редагувати дані. Редагувати файли можна прямо на GitHub (значок олівця) або в будь-якому текстовому редакторі.

## 1. Правила запису формул

Формули записуються в LaTeX між знаками долара: `$x^2 + 3x$`. Окрема формула по центру: `$$ ... $$`.

**У файлі `js/data.js`** зворотний слеш потрібно писати **двічі**:

```js
task: "Спростіть: $\\frac{x}{2} + \\frac{x}{3}$"
```

Якщо написати один слеш, JavaScript «з'їсть» його, і формула зламається. Для цього є перевірка: `node tools/validate.js`.

**У файлі `js/alt-solutions.js`** використовується `String.raw` — тут слеш пишеться **один раз**:

```js
html: String.raw`Спростіть: $\frac{x}{2} + \frac{x}{3}$`
```

## 2. Додати завдання в тренажер

У `js/data.js` знайдіть потрібну тему й масив `exercises`. Додайте об'єкт:

```js
{
  level: 2,                       // 1 початковий, 2 середній, 3 достатній, 4 високий
  task: "Розв'яжіть рівняння: $3x - 5 = 10$.",
  solution: "$3x = 15 \\Rightarrow x = 5$. Відповідь: $5$."
}
```

Номер завдання в тренажері — це його позиція в масиві (перше = 1). Якщо вставляєте завдання в середину списку, перевірте, що номери в `js/alt-solutions.js` досі вказують на правильні завдання.

## 3. Додати розв'язання за підручником

У `js/alt-solutions.js`:

```js
"topic-4": {
  8: {                                  // завдання №8 у темі «Формули скороченого множення»
    ister: {                            // id підручника з js/textbooks.js
      title: "§ 15",                    // підпис (необов'язково): параграф або назва способу
      html: String.raw`Власний опис способу розв'язання, формули в $...$`
    },
    merzliak: { html: String.raw`...` }
  }
}
```

Id підручників: `intelekt`, `merzliak`, `ister`, `kravchuk`, `bevz`, `tarasenkova`. Для способу, який не належить жодному підручнику, використовуйте `other`.

Біля завдання з'являться вкладки: «Покроково» + додані підручники. Якщо учень у «Панелі підручників» обрав свій підручник, його вкладка відкриватиметься першою.

> **Авторські права.** Не копіюйте розв'язання з підручників. Викладайте підхід власними словами й вказуйте параграф.

## 4. Заповнити «тема → параграф»

У `js/textbooks.js` знайдіть `TEXTBOOK_MAP`:

```js
const TEXTBOOK_MAP = {
  "topic-3": { ister: "§ 12–18", merzliak: "§ 9–13" },
  "topic-4": { ister: "§ 19–22" }
};
```

Ці дані показуються в «Панелі підручників» і в заголовку теми — для учня, який обрав «свій підручник».

## 5. Додати або змінити підручник

У `js/textbooks.js` у масив `TEXTBOOKS` додайте об'єкт з унікальним `id`, `short` (коротка назва для вкладки), `title`, `authors`, `publisher`, `year`. Для основного підручника поставте `main: true`.

## 6. Додати нову тему

У `js/data.js` у масив `topics` додайте об'єкт за зразком існуючих: `id` (наприклад, `"topic-7"`), `icon`, `shortTitle`, `title`, `nushIndex`, `goal`, `theoryHTML`, `exercises`. Тема з'явиться в меню автоматично. Для розділів теорії використовуйте готові класи оформлення: `card`, `rule-box`, `life-box`, `example-box`.

## 7. Додати інтерактив

У `js/widgets.js` додайте функцію в об'єкт `WIDGETS` (за зразком `linear-graph`) і вкажіть її тему в `WIDGETS_BY_TOPIC`:

```js
const WIDGETS_BY_TOPIC = {
  "topic-5": ["linear-graph"],
  "topic-1": ["my-new-widget"]
};
```

## 8. Перед публікацією

```
node tools/validate.js
```

Скрипт повідомить про незакриті формули, пропущені слеші, неправильні номери розв'язань та невідомі підручники. Якщо в системі встановлено пакет `katex` (`npm install katex`), додатково перевіряється синтаксис кожної формули.

## 9. Перевірка своїх завдань

Перед додаванням нового завдання самостійно розв'яжіть його й звірте відповідь: у публічному підручнику помилка в еталоні вводить в оману учнів. Особливо уважно перевіряйте умови задач із текстом: числа в умові та в розв'язанні мають збігатися.
