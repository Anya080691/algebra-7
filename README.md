# 📐 Алгебра 7 клас — інтерактивний підручник

Самостійний інтерактивний підручник для учнів 7 класу: повторення курсу 5–6 класів, теорія з прикладами та задачами з життя, тренажер із самоперевіркою й підсумкова робота. Основа для саморозвитку та підготовки до НМТ.

Основний підручник курсу — «Інтелект України». У панелі підручників також зібрані підручники алгебри 7 класу НУШ інших авторів, а біля завдань можна відкривати розв'язання різними способами.

Це статичний сайт без збірки та серверної частини: його можна розмістити на GitHub Pages.

## Що вже є

| Розділ | Зміст |
|---|---|
| **7 тем** | 0. Повторення (5–6 кл.) · 1. Цілі вирази, тотожності · 2. Степінь · 3. Одночлени та многочлени · 4. Формули скороченого множення · 5. Функції, лінійна функція · 6. Лінійні рівняння та системи |
| **Теорія** | правила, покрокові приклади, життєві приклади (фінанси, фізика, програмування, будівництво) |
| **Тренажер** | 18 завдань у кожній темі, 4 рівні складності. Учень розв'язує, позначає «правильно / не вийшло», потім відкриває розв'язання |
| **Розв'язання за різними способами** | вкладки біля завдання: «Покроково» + альтернативні способи та підходи конкретних підручників |
| **Самоперевірка** | 24 завдання (вибір, відповідність, коротка числова відповідь, розгорнута задача із самооцінкою), оцінка за 12-бальною шкалою, результат за рівнями |
| **Прогрес** | позначки й найкращий результат зберігаються в браузері учня (без реєстрації) |
| **Панель підручників** | список підручників, вибір «мого підручника», таблиця «тема → параграф» |
| **Інтерактив** | графік лінійної функції `y = kx + b` з повзунками (тема 5) |

## Як опублікувати на GitHub Pages

1. Створіть **публічний** репозиторій і завантажте в корінь усі файли цієї папки.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/ (root)` → **Save**.
3. Через 1–2 хвилини сайт буде за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

## Запуск на власному комп'ютері

Достатньо відкрити `index.html` у браузері. Для формул потрібен інтернет (бібліотека MathJax підключається з CDN).
Щоб запустити локальний сервер: `python3 -m http.server 8000`, далі `http://localhost:8000`.

## Структура репозиторію

```
index.html              сторінка
css/style.css           оформлення
js/data.js              теми, теорія, тренажер, самоперевірка
js/textbooks.js         підручники та таблиця «тема → параграф»
js/alt-solutions.js     розв'язання різними способами / за підручниками
js/widgets.js           інтерактивні віджети
js/app.js               логіка застосунку
tools/validate.js       перевірка даних перед публікацією
docs/ADDING_CONTENT.md  інструкція для автора
```

## Як додавати й змінювати матеріали

Усе описано в [docs/ADDING_CONTENT.md](docs/ADDING_CONTENT.md). Перед кожною публікацією запускайте:

```
node tools/validate.js
```

Скрипт знаходить найпоширеніші помилки: незакриті формули, пропущені подвоєння `\`, неправильні номери розв'язань. На GitHub він запускається автоматично при кожному оновленні.

## Авторське право

- Не копіюйте в репозиторій тексти, задачі й розв'язання з підручників: вони захищені авторським правом. Описуйте підхід власними словами та вказуйте підручник і параграф.
- Оберіть і додайте ліцензію на власні матеріали (наприклад, Creative Commons BY-SA 4.0 — файл `LICENSE`).

## Плани розвитку

- більше теорії й розібраних прикладів у кожній темі;
- розв'язання за підручниками Мерзляка, Істера, Кравчука та ін. (вкладки вже підтримуються);
- завдання у форматі НМТ;
- нові віджети: калькулятор відсотків, графічний розв'язок системи рівнянь, тренажер формул скороченого множення;
- версія для друку.
